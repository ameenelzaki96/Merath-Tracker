Update the tracker data

Al‑Merath · encrypted export

1. Choose your Excel file

Pick the current AlMerathTracker.xlsx. Everything happens in your browser — the file is never uploaded anywhere.

Use the same passcode the viewer asks for (currently 1996). If you change it here, tell the family the new one.

2. Then update your repo

  1. Click Generate data.enc above once the check passes — your browser downloads a file named data.enc.
  2. In your GitHub repo: Add file → Upload files, drop in data.enc (replacing the old one), and Commit.
  3. GitHub Pages redeploys in a minute. The tracker link now shows the new numbers — no need to touch index.html.

The downloaded file is encrypted with your passcode, so it's safe to keep in the repo even though the repo/link is public.
